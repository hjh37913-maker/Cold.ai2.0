# Features

## Core features

- voice-first interaction shell;
- AI intent routing;
- task plan generation;
- local memory support;
- automation rule model;
- permission-aware behavior;
- security confirmations for sensitive actions;
- system diagnostics report;
- professional command center dashboard.

## Planned extensions

- calendar engine for events and reminders;
- contacts engine with fuzzy matching;
- media controls and notification center integration;
- weather and web providers;
- camera, gallery, and file access flows;
- background automation scheduling;
- deeper offline behavior.

## Product quality constraints

- no fake actions;
- no decorative AI UI that does not work;
- no hidden background recording;
- no hidden data transmission;
- no misleading feature labels.
